# JEMCompat Project Rules

- Sirok is no longer campaign-gated; keep the Sandworm Nest's single native encounter and never create a second JEM-owned combat entity because the removed TNT replacement path caused duplicate solid bosses.
- Preserve `com.siirio.jemcompat.client.AdvancementScreenEvents.directClick` as a compatibility shim because the installed BetterAdvancements bytecode directly invokes that exact binary name; removing it causes a click-time `NoClassDefFoundError` even though the real handler lives in JEMAchievementGuide.
- Elemental ignition must use the explicit `jemcompat:igniting_impact_items` tag and never infer heat from block light emission, because redstone lights, closed lamps, glowstone, and enclosed lanterns are luminous without being exposed fire.
- Freezing impacts affect players and mobs, deal at most one health point per ten seconds without a nonlethal floor, and render a translucent blue animated-model overlay because particles alone do not clearly communicate the frozen state and cold must still be able to finish a kill.
- The frozen blue overlay must be a renderer layer rather than a direct model render from `RenderLivingEvent.Post`, because only a layer inherits the living renderer's prepared transforms and avoids upside-down or misaligned tint geometry.
- The frozen renderer layer must remain visibly saturated and its `ticksFrozen` lifetime must match the custom Slowness lifetime, because an impact-only flash does not communicate that the target is still slowed.
- When snowball Slowness already applies but blue presentation is missing on modded entities, fix the client renderer path rather than expanding gameplay targets; tint the actual living-entity render buffer so native poses and animations remain intact across custom renderer hierarchies.
- Modded torch items may ignite through their native `TorchBlock` type while other luminous blocks still require the explicit ignition tag, because open flame and light emission are different properties.
- Elemental ignition remains limited to `Mob` targets; never ignite block entities, chests, dropped items, or arbitrary entities merely because they are entities.
- Jade entity and ingredient names must remain translation components until client rendering, and breedable animals expose cached native `isFood` matches with item icons, because server-resolved display text ignores the active client language.
- Jade must collapse large breeding-food sets into one localized category or generic line with a rotating valid item icon, because rendering one line per matching modded food can cover the screen.
- Curated JEI assigns weapons, shields and combat-capable tools by their real class, main-hand attributes, use animation or an explicit audited compatibility tag before name hints; every stack has one primary leaf category, because ID-only matching misses modded equipment and duplicate categories make navigation inconsistent.
- Universal leads extend the native `Mob` leash state to every otherwise-refusing mob, while players and non-mob technical entities remain ineligible, because arbitrary `Entity` attachment required a separate renderer that produced malformed ropes.
- Kaleidoscope End Void Walker fake-air support resets accumulated fall distance only while it is actually supporting the player, because its synthetic air collision does not perform a normal block landing and otherwise charges the later descent as one long fall.
