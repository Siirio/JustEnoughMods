# JEM Compat

`jemcompat` owns isolated native compatibility adapters and their related pack policies. Required metadata: Forge `[47.4.10,)`, Minecraft `[1.20.1,1.21)`, Sophisticated Backpacks `3.26.14.2226`, Curios `5.14.1+1.20.1`, and JEM Rewards `[1.1.0,)`. Builds target 1.20.1. WorldTier, Identity, Jade, JEI, Enhanced AI, and native boss content are optional. Other compile-only installed APIs are not additional runtime requirements. [Inventory](../../Docs/universal/README.md).

The curated JEI catalog and standard JEI overlay are mutually exclusive presentation modes. Switching to standard JEI hides and deactivates the curated category search widget and clears its focus. Switching back restores that widget without changing its query or native JEI search state.

The curated catalog uses one schema-2 exact-ID manifest. Weapons include separate shield, smithing-template and training leaves. Components is a top-level leaf for reviewed creature drops and crafting parts. Wearables include Armor, Mob Armor, and Dolls. The Dolls leaf contains doll items only. Companions and Transport can show reviewed spawn eggs as exact additional views while Spawn Eggs remains the primary assignment.

In the player inventory, vanilla storage screens and real storage cells of the installed Sophisticated Backpacks and Sophisticated Storage menus, Delete removes one item from the hovered slot and Shift+Delete removes that slot's entire stack. The server validates the open menu, slot, item and count before native extraction. The Sophisticated adapter accepts only its reviewed menu and Core versions and rejects inaccessible, infinite, upgrade and other non-storage slots. Focused native text boxes and JEI/JEM search retain their keys; crafting/result and unreviewed third-party virtual slots retain their native behavior. TrashSlot's separate trash control and matching-item sweep are retired.

The former Pack Core compatibility scope now belongs here. Excavation I mines one face-directed 3x3 plane and II mines one 7x7 plane through the same native mining mixins and matching white highlight. This module also owns biome probability codec/data, native grave compatibility, Bountiful/season crop policies and combat capability resources. `jem_pack_core:excavation`, `jem_pack_core:creature_spawn_probability` and corresponding translations/data paths remain stable compatibility IDs. They do not require a Pack Core mod entrypoint.

Every adapter must retain the exact native owner API, signal, inventory and presentation. Optional absence skips only that adapter; an installed incompatible contract fails visibly. Equipment classification delegates to the canonical WorldTier policy when present and uses native equipment classes/attributes otherwise. The Better Advancements binary shim retains its exact class/method name and dispatches to Guide only when installed.

Void Walker F7 uses the persisted server toggle and its existing client status message. While disabled, the exact enchantment's effective living-entity level is zero for Kaleidoscope End's native air-collision and jump-lock handlers, including after ordinary or Epic Fight movement. Eligibility to toggle back on reads the actual enchanted boots. Active movement, crouch descent and fall-distance reset on actual synthetic support remain native. The former optional redirects into vanilla methods were removed because their target calls live in separate native Mixin handlers. Matching client/server JEMCompat is required. Runtime movement acceptance remains pending.

Aircraft rules use logical-server authority in integrated and dedicated worlds. Identity checks remain authoritative when Identity is installed; without it, operations use the existing server player session. Dedicated login/connectivity adaptations remain physically dedicated. No event scheduler is introduced by these adapters. The retired backpack extension is recorded in [backpack documentation](../../Docs/backpack/README.md).

The transport and carriage source candidate owns universal backpack burden, removal of portable Inception and stack upgrades, 128-count native block stacks inside shulker boxes, portable-container non-nesting, vanilla minecart stack and route caps, cheaper rail batches, six-block elytra takeoff, and the eight-boost firework batch. The logical server owns movement and boost state. The client only renders the synchronized burden indicator. Create trains, ice boats, TPA, existing mount and wagon rules, and the existing biplane contract are unchanged. The shulker rule has no legacy migration because the user confirmed that no player owns a shulker box. Exact numbers and unresolved runtime checks are in [the transport plan](../../Docs/plans/2026-11-19-transport-and-carriage.md).

The sole former Menu Support consumer now uses private `client.menu.VanillaGuiPlayers` source. No Menu Support runtime/embed dependency remains. Source-owned native compile inventory defaults to project-relative `../../Client/ManagedPack`, with `jem_instance`/`JEM_INSTANCE` override. These source contracts do not claim an exercised missing-mod JVM matrix, integrated game session, menu acceptance or rendering parity. [DEVELOPMENT](../../Docs/DEVELOPMENT.md) owns engineering/release and [universal installation](../../Docs/universal/INSTALL.md) owns archive setup.

Native crop tags and the optional Spawn sunflower seed-growth adapter are documented in [Serene Seasons crop compatibility](SEASONS.md), including exact coverage, preserved windows and growth-route exceptions.

For the exact installed AudioYT 1.0.1, JEMCompat replaces its repeated 33x17x33 nearby-block search with event-driven discovery of jukebox block entities when an already loaded chunk enters the server. AudioYT retains ownership of disc changes, playback state and its loaded-only known-jukebox checks. The adapter never requests a missing chunk.

For the exact installed Paraglider 20.1.3, natural spawners retain the native Spirit Orb exploration reward. A spawner placed by a player receives persistent provenance, and Paraglider's spawner loot modifier skips that block on every later break. Moving a discovered spawner therefore cannot turn the finite reward into a renewable loop.
