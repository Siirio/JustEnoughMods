# JEM Compat

`jemcompat` owns isolated native compatibility adapters and their related pack policies. Required metadata: Forge `[47.4.10,)`, Minecraft `[1.20.1,1.21)`; builds target 1.20.1. WorldTier, Identity, Jade, JEI, Enhanced AI, native boss content are optional. Compile-only installed APIs are not additional runtime requirements. [Inventory](../../Docs/universal/README.md).

In the player inventory, vanilla storage screens and real storage cells of the installed Sophisticated Backpacks and Sophisticated Storage menus, Delete removes one item from the hovered slot and Shift+Delete removes that slot's entire stack. The server validates the open menu, slot, item and count before native extraction. The Sophisticated adapter accepts only its reviewed menu and Core versions and rejects inaccessible, infinite, upgrade and other non-storage slots. Focused native text boxes and JEI/JEM search retain their keys; crafting/result and unreviewed third-party virtual slots retain their native behavior. TrashSlot's separate trash control and matching-item sweep are retired.

The former Pack Core compatibility scope now belongs here. Excavation I mines one face-directed 3x3 plane and II mines one 7x7 plane through the same native mining mixins and matching white highlight. This module also owns biome probability codec/data, native grave compatibility, Bountiful/season crop policies and combat capability resources. `jem_pack_core:excavation`, `jem_pack_core:creature_spawn_probability` and corresponding translations/data paths remain stable compatibility IDs. They do not require a Pack Core mod entrypoint.

Every adapter must retain the exact native owner API, signal, inventory and presentation. Optional absence skips only that adapter; an installed incompatible contract fails visibly. Equipment classification delegates to the canonical WorldTier policy when present and uses native equipment classes/attributes otherwise. The Better Advancements binary shim retains its exact class/method name and dispatches to Guide only when installed.

Aircraft rules use logical-server authority in integrated and dedicated worlds. Identity checks remain authoritative when Identity is installed; without it, operations use the existing server player session. Dedicated login/connectivity adaptations remain physically dedicated. No event scheduler is introduced by these adapters. The retired backpack extension is recorded in [backpack documentation](../../Docs/backpack/README.md).

The sole former Menu Support consumer now uses private `client.menu.VanillaGuiPlayers` source. No Menu Support runtime/embed dependency remains. Source-owned native compile inventory defaults to project-relative `../../Client/ManagedPack`, with `jem_instance`/`JEM_INSTANCE` override. These source contracts do not claim an exercised missing-mod JVM matrix, integrated game session, menu acceptance or rendering parity. [DEVELOPMENT](../../Docs/DEVELOPMENT.md) owns engineering/release and [universal installation](../../Docs/universal/INSTALL.md) owns archive setup.

Native crop tags and the optional Spawn sunflower seed-growth adapter are documented in [Serene Seasons crop compatibility](SEASONS.md), including exact coverage, preserved windows and growth-route exceptions.
