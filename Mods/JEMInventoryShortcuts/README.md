# JEM Inventory Shortcuts

JEM Inventory Shortcuts is a Forge 1.20.1 mod for server-validated Delete and Shift+Delete actions. Delete removes one item from the hovered physical slot, while Shift+Delete removes the complete hovered stack

## Build

Run `./gradlew clean build` with Java 17. JEI and Sophisticated storage integrations are optional. Unknown, inaccessible, infinite, result, upgrade, and virtual slots fail closed
