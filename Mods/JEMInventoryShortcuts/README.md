# JEM Inventory Shortcuts

JEM Inventory Shortcuts is a Forge 1.20.1 project for server-validated Delete and Shift+Delete actions. The scaffold is public-build ready, while the key handler, network path, and optional storage adapters remain in migration from JEMCompat

## Build

Run `./gradlew clean build` with Java 17. The initial scaffold has no mandatory storage dependency and does not read a local Minecraft profile
