# JEM Freecam

JEM Freecam is a client-only Forge 1.20.1 project for a collision-limited detached camera. The scaffold is public-build ready, while the controller and optional Epic Fight hooks remain in migration from JEMCompat

## Build

Run `./gradlew clean build` with Java 17. The build resolves Forge and Mixin tooling from public repositories and does not read a local Minecraft profile
