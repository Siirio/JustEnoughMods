# JEM Drill Durability

JEM Drill Durability is a Forge 1.20.1 Create addon that owns drill wear, servicing, reduced worn speed, and replacement behavior. Jade presentation is optional at runtime

## Requirements

- Minecraft 1.20.1

- Forge 47.4.10 or newer in the 47.x line

- Create 6.0.8

- Jade 11.x is optional

## Build

Run `./gradlew clean build` with Java 17. Create development artifacts follow the official Create Maven guidance and Jade resolves from Modrinth Maven
