# JEM Adaptive Culling

JEM Adaptive Culling is a client-only Forge 1.20.1 rendering optimization with bounded entity and block-entity visibility caches. Embeddium and Oculus are optional compatibility integrations

## Build

Run `./gradlew clean build` with Java 17. Optional Oculus API symbols resolve from Modrinth Maven and the build does not read a local Minecraft profile

No public performance claim is made until real gameplay FPS is measured
