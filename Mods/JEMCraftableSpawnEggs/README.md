# JEM Craftable Spawn Eggs

This Forge 1.20.1 source project owns the spawn-egg recipes, fallback egg registrations, spawner programming rules, per-spawner cooldown state, and player-placed spawner loot rule that previously belonged to JEMCompat

The project is retained for future independent use. It is intentionally absent from the JEM client and server inventories

The extracted source currently contains 425 generated recipes and 24 fallback item registrations. These are the exact files present in JEMCompat at extraction time. Run tools/generate_spawn_egg_recipes.py against a reviewed registry export before a future release
