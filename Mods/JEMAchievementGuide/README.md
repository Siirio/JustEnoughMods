# JEM Achievement Guide

`jem_advancements` owns authoritative advancement criteria/providers, curated native placements and RU/EN Patchouli reference content. It also hosts the optional content-aware FTB book observer. Required metadata is Forge `[47.4.10,)`; the build targets Minecraft 1.20.1. There is no mandatory third-party guide/quest mod. Optional FTB support is audited for Quests `2001.4.22` with its native required libraries. [Inventory](../../Docs/universal/README.md)

The former Pack Core guide source/resources and `src/main/advancements` authoring inputs/tools now belong here. Preserve surviving `jem_guide:*` IDs, exact proof, criteria names, native placement policy and supported gameplay translations. The 2026-10-24 user request removes advancement notes and Mechanics from `jem_advancements:just_enough_guide`. The book retains five reference sections. Optional native event/mixin adapters load only for available owners. The installed Better Advancements binary shim remains compatible through an inert `directClick` method, without opening book entries

Before the native advancement manager applies resources, the curated loader filters unavailable registry namespaces/item references and prunes orphan parent chains. Source IDs remain available for returning content; unavailable references do not become fabricated objectives. Guide descriptions and presentation do not own domain progression.

The marked universal FTB book preserves authored quest/task IDs and native team data. Its optional adapter uses the inspected native pre-load folder seam to create a world-local content projection before native parsing. Missing/off domains become hidden inert historical records, with their original task maxima; dependency dormancy propagates. Races and Twelve Eyes use canonical API proof, not inventory proxies. Native FTB remains responsible for team progress, synchronization and claims. Unrelated unmarked books are unchanged; persistent author edits belong in the canonical config, not an old generated projection.

New books use the actual five Races. Events remain unavailable in integrated worlds or hosts without explicit dedicated event opt-in. Economy absent/off hides only monetary objectives; Settlements retains its native emerald contract. There is one universal authored book, not a second progression owner.

The Adventure Atlas is authored in `tools/questbook/book.json` and compiled by `tools/compile_questbook.py` into the canonical ManagedPack FTB configuration. UI Rescue v3 migrates all 602 cards into seven real visible chapters without a hub or named sidebar groups. Seven invisible historical archives retain retired identities. The exact before/after progression contracts and resource/geometry receipts are linked from [the quest book owner](../../Docs/quests/README.md). Native FTB owns team progress and claim presentation, while JEMRewards persists personal item entitlements. No campaign, race, economy or event history is reconstructed in the book. Server projection serializes native text components without invoking FTB's client-only plain-text parser. Runtime GUI readability and clicks remain pending the user's manual Minecraft review.

`build.gradle` defaults native compile inventory to project-relative `../../Client/ManagedPack`, with optional `jemRuntimeRoot`/`jem_instance`/`JEM_INSTANCE` override. Compile-only installed API JARs do not make runtime integrations mandatory. Existing authoring/validation tools are not automatic build/runtime prerequisites. This README does not claim native loader/Mixin, dynamic book reload, localization layout or player acceptance. [DEVELOPMENT](../../Docs/DEVELOPMENT.md) owns packaging and delivery.

The universal [JEM Handbook](../../Docs/handbook/README.md) extends the same `jem_advancements:just_enough_guide` identity with one native Patchouli item and a dirt-plus-stick recipe. Every real player receives that exact handbook once on the first login after the delivery is installed, including players whose account predates the update; the persisted entitlement survives death, and an already carried handbook is never duplicated. Authored navigation/boss/item sources live in `src/main/handbook`; enchantment explanations serve native Patchouli processors and tooltips from one resource. Native manual adapters preserve personal research and meaningful NBT. The optional client extension, bounded server manual-open channel and coverage/delivery limits are documented there. The FTB quest book remains a separate native quest/progress owner and is preserved in this artifact.
