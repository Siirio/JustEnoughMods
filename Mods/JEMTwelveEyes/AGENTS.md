# Project Rules

- This mod exclusively owns the Twelve Eyes campaign while preserving the `jemcompat` content namespace and `jemcompat_main_campaign` SavedData name, because changing those stable IDs would break current worlds and advancements.
- The campaign contains exactly twelve MAIN bosses and no End-only MAIN boss; Ender Guardian remains optional post-End content.
- MAIN and subordinate campaign roles do not determine World Tier participation; World Boss Tiers owns scaling and unique-defeat progression.
- Subordinate bosses receive no new JEM gate and remain native-first; only MAIN awakening may check the approved world-global prerequisite pool.
- Spawn eggs, `/summon`, and `/kill` remain valid campaign verification paths without game-mode checks.
- Lethal prerequisite damage handlers must receive canceled Forge events because animated bosses such as Skor may cancel their terminal damage/death path before ordinary death listeners run.
- Every campaign prerequisite must have redundant exact defeat proof: world-global death/lethal handling plus its own `player_killed_entity` campaign criterion, with native boss advancements reconciled into the same idempotent world flag because animated death implementations can bypass any single Forge event.
- Boss locator items are registered under the stable `jemcompat` namespace for all twelve MAIN bosses and all sixteen campaign sub-bosses, and cartographers sell them without performing structure searches during trade generation.
- Locator trades use stable per-trader selections: some cartographers have none, map cartographers offer two locators at level one and two more at level two, and wandering traders offer one or two from the full pool, because assembling all twelve should require meeting several traders without hiding maps behind level three or higher.
- Using a locator must keep the item, replace the matching persistent Xaero waypoint without duplicates, and immediately center Xaero World Map on the located structure and its dimension because the user explicitly requires both a visible marker and direct map navigation.
- Campaign structure-backed encounters keep only their original native structure sets and exclusion rules; Sparse Structures exemptions restore native spacing only for the exact story structure IDs so non-story structures remain sparse without duplicate campaign placements.
- Boss locator structure searches run asynchronously with one active search per player, then return waypoint and Xaero UI work to the main threads because synchronous locate freezes server ticks.
- Locator searches use the target dimension's shared spawn as their origin, reject destinations beyond 8192 horizontal blocks, and Nether locators can only be activated while the player is in the Nether.
- Sub-bosses without a native registered structure receive one exact saved encounter site within the campaign radius; the matching locator prepares it on demand through non-blocking chunk futures, sites are spaced apart, reject intersecting native structure starts, and spawn their persistent boss only when a player approaches. Never scan biomes or force chunks from a startup/server-tick loop because it freezes the integrated server.
- Only MAIN structures with approved subordinate prerequisites add a campaign lock to the shared invisible physical structure shell; it never teleports or rewrites movement, shows missing-boss feedback without blocking controls, and global unlock removes only the campaign lock immediately.
- MAIN unlock state is derived directly from all approved world-global prerequisite defeat flags; a separate cached unlock marker may announce the transition but must never keep a completed structure locked.
- Locked-structure feedback uses the existing full-screen presentation and a ten-second message interval while the physical shell alone blocks entry, because repeated position correction and message spam make the boundary unusable.
- Do not add old-world migration code.
- Campaign Eyes may be tossed normally, while their dropped item entities remain invulnerable, non-expiring, and recoverable from the void because protection prevents permanent loss without trapping the item in the inventory.
- The world's first credited Ender Dragon victory, including Creative `/kill` verification, globally unlocks one personal sequence for every player on their first later exit through the End portal leading to the final credits: keep the vanilla ending uninterruptible for twelve seconds even with Escape, then run exactly nine seconds of `IT IS` followed by `NOT THE END`, close the screen without moving the player from the vanilla portal exit, and never require that player to have killed the dragon personally; never substitute entering the End for this exit trigger because the user explicitly requires the post-dragon credits portal, and no ellipsis phase is part of the approved sequence.
