# JEM Twelve Eyes

This module owns the strict campaign, original MAIN/prerequisite graph, Eyes, locators/sites, post-End progression and ending. Stable content namespace `jemcompat` and SavedData name `jemcompat_main_campaign` remain unchanged. Required metadata: Forge `[47.4.10,)`, Minecraft `[1.20.1,1.21)`; production builds target 1.20.1. Native content mods, WorldTier and Xaero are metadata-optional; optional loading does not make an incomplete campaign playable. See the [inventory](../../Docs/universal/README.md).

The bundled `jem_twelve_eyes/campaigns.json` contains exactly the same twelve original MAIN bosses, Eyes and approved prerequisites. A conflicting external definition is rejected. This roster never adapts to currently installed bosses, awards replacement Eyes or substitutes victory proof. WorldTier separately owns numerical scaling and unique-defeat tiers.

A new incomplete world remains campaign-inactive and can use the vanilla End path. Activation requires exact entity/Eye/prerequisite registrations plus required native structure tags/dimensions. Existing active campaign data remains active if content is removed: preserve its progress, report missing content and fail closed at MAIN Start and portal operations until content returns. Inactive-world vanilla frame use does not mutate global EndRem config. Absent-content campaign rewards, sites, locators and trades do not invent missing encounters.

`CampaignApi.hasRequiredContent()` is a pure registry query suitable before world levels exist, including recipe reload. `isActive`, `isAvailable`, `mainDefeated`, `complete` and `startBlockReason` observe the world-owned state after levels exist. Consumers must not treat an ordinary Eye inventory or advancement display as campaign completion. Authoritative defeat/lethal/native advancement signals still converge on the same idempotent world proof.

Native structure terrain remains freely accessible. Approved prerequisites guard awakening/Start; no physical barrier or corrective teleport is restored. WorldTier supplies solo admission when installed without Server; otherwise native campaign guards remain this module's responsibility. Optional Xaero work stays behind its client adapter.

The complete former Pack Core campaign scope moved here: definition, advancements, tags, 28 campaign locator models, translations, post-End items/sounds and the End credits hook. The original first credited world dragon victory and personal post-credits sequence are preserved. No source namespace, save or registry identity was renamed. Production source/resources are not proof of a completed runtime campaign or player acceptance. [Engineering](../../Docs/DEVELOPMENT.md) and [Boss Fight](../../Docs/events/BOSS_FIGHT.md) own the broader integration contract.
