# JEM Seasons HUD

JEM Seasons HUD is a client-only Forge 1.20.1 project for localized day and time presentation with optional Serene Seasons data. The scaffold is public-build ready, while the HUD remains in migration from JEMCompat

## Build

Run `./gradlew clean build` with Java 17. The build does not require Serene Seasons to compile the initial scaffold and does not read a local Minecraft profile
