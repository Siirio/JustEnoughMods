# JEM Seasons HUD

JEM Seasons HUD is a client-only Forge 1.20.1 inventory HUD for localized day and world time presentation. When Serene Seasons is installed, it also shows the synchronized native season and progress

## Build

Run `./gradlew clean build` with Java 17. The optional Serene Seasons API resolves from its published Curse Maven artifact and the build does not read a local Minecraft profile
