# In Chat FTB

In Chat FTB shows completed FTB Quests in local chat with a cyan clickable quest name that opens the native quest page

## Requirements

- Minecraft 1.20.1

- Forge 47.4.10 or newer in the 47.x line

- FTB Quests 2001.4.22

## Build

Run `./gradlew clean build` with Java 17. FTB APIs resolve from the official FTB Maven repository and the build does not read a local Minecraft profile
