# Settlements dashboard direction —2026-10-19

All three originals supplied and positively selected by the user for UI restructure.
No reference pixels are cropped into production assets. Text and numbers inside the
images are visual examples, not instructions to change simulation or create actions.

-01-town: prominent name/wood header; stone sidebar, blue selected tab; parchment
  summaries; readable recessed treasury; compact comfort groups and edit/delete.
-02-residents: master/detail composition retaining roster while inspecting a named
  resident; real portrait, needs, actionable complaint hierarchy, native assignments.
-03-happiness: summary strip, legible factor rails, grouped complaints, distribution.

Extract chunky pixel framing, pale/dark material contrast, native-size semantic
icons, separated text/value/rail hierarchy and quiet whitespace. Preserve four
navigation destinations, exact six90-point weights plus10 activities, four actual
comfort categories including animals, and native HOME/JOB_SITE ownership. Do not
add friendship simulation, manual assignment endpoints, fixed taxes/penalties or
fictional per-resident income simply because the concept shows them.

Frontend information design: consistent shell, one primary task per view, local
selection, adjacent detail, scrolled lower groups and always reachable native
controls. Minecraft styling is owned by the exact GUI Taste Engine Pair. No web
fashion or typography is transferred into Minecraft.

Palette: parchment #ead9b8, ink #342b26, charcoal #30323d, selected blue #236fae,
gold #c8a55b, foliage #638844. Native Minecraft font, normal9px body, modest1.4x
header; no scaled-down body text. Full shell up to860x548 logical pixels; narrow
Minecraft view uses compact navigation/list/detail rather than tiny split panes.

Town: summary strip -> treasury -> isometric town with comfort beside it -> money,
name and confirmed removal controls. Residents: roster left, persistent detail right;
narrow view retains the same actions in the existing single-column navigation.
Happiness: current summaries -> six weighted factors -> current housing complaints
-> happiness distribution. Chests retain actual native item contents/actions.

New editable art: ../../source/dashboard-r2. Runtime owner: SettlementScreen with
SettlementDashboardArt. Current source/export is a candidate; real-game visual
acceptance is not implied by design references or successful compilation.
