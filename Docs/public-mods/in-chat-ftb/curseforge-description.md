# In Chat FTB

Posts completed FTB Quest names in chat as cyan links that open the native quest page

## Requirements

- Forge 47.4.10+
- Minecraft 1.20.1
- FTB Quests 2001.4.22

## Optional integrations

- None

## Compatibility and support

- Minecraft 1.20.1 with Forge 47.4.10 or newer in the 47.x line
- Client-only and not required on a dedicated server
- Report issues with the exact mod version, Forge version, dependency versions, and relevant log
