# JEM Freecam

Adds a collision-limited client free camera while the real player remains under normal server authority

## Requirements

- Forge 47.4.10+
- Minecraft 1.20.1

## Optional integrations

- Epic Fight 20.14.17

## Compatibility and support

- Minecraft 1.20.1 with Forge 47.4.10 or newer in the 47.x line
- Client-only and not required on a dedicated server
- Report issues with the exact mod version, Forge version, dependency versions, and relevant log

This description is prepared for review. The project and artifact remain private until runtime, media, and authorization gates are complete
