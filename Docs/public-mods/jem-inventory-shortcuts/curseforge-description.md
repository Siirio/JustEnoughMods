# JEM Inventory Shortcuts

Adds server-validated Delete and Shift+Delete actions for reviewed physical inventory slots

## Requirements

- Forge 47.4.10+
- Minecraft 1.20.1

## Optional integrations

- JEI
- Sophisticated Core 1.5.15.2427
- Sophisticated Backpacks 3.26.14.2226
- Sophisticated Storage 1.5.9.2197

## Compatibility and support

- Minecraft 1.20.1 with Forge 47.4.10 or newer in the 47.x line
- Install the matching compatible artifact on the client and logical server
- Report issues with the exact mod version, Forge version, dependency versions, and relevant log
