# Five native coin icons

User request: overhaul section15, clear native Minecraft item pixel art; registry IDs and values preserved. Codex selected original integer-grid SVG material layers with16×16 exports. Copper is small/russet with a recessed square; Silver has a tall inset and cool neutral rim; Gold is broader with a square stamped border; Aether is a cyan bevelled square; Arcane has a violet angular silhouette and diamond stamp. Shared upper-left lighting, five-color material palettes, no antialiasing/dithering/glow. Each SVG has editable rim, face, bevel, stamp and highlight groups. `design.json` records palettes. `previous/` preserves previous source exports/models.

Reference study: independently selected Beebs Currency coin silhouettes from https://www.curseforge.com/minecraft/mc-mods/beebs-currency (actual reference inspected; compact coherent material tiers, not copied). This reference is Codex-selected, not labelled user taste. Generated `generated-design-reference.png` is a composition proposal only; its smooth shading does not meet native pixel production. No source/reference pixels were cropped/copied into the production SVGs. The native set was authored independently as original integer-pixel vector layers and exported without resampling through System.Drawing. `contact-sheet.png` shows4× nearest-neighbour and1× views, inspected in this session. Native item-generated models replace the fixed round extrusion so distinct silhouettes survive in inventory and hand; glyph font still uses the same front PNG path. Values remain1/10/100/1000/10000 and all five registry IDs are unchanged.

In-game inventory, merchant, market, hand and tooltip acceptance at multiple GUI scales remains pending; source/export review is not player acceptance.
