## What these images tell us

Selected positives show authored elemental silhouettes, tapered directional
forms, textured or broken edges, strong core/body contrast, coherent families
of projectiles/impacts and deliberate phase shapes. Circular carriers and
controlled glow can work when the actual art supplies their identity. The
user explicitly requested **pixelated** effect language.

Negative JEM captures reject thin ground marks, uniform green rings/links,
generic burning plus an orange ring, an untextured purple circle/straight strip,
and the smooth vine/tornado. Recoloring these primitives, adding more emitters,
or blurring them does not solve the rejected appearance. Still images establish
appearance; they do not prove timing, all-angle readability or real game fit.
