## Производство и редактирование

- Канонический внешний study: `C:/MyProjects/Coding/Solo/Ultimate-Skills/Taste-Engine/aseprite/Projects/JEM-1.20.1/Studies/Smp-styles-2026-10-21`.
- В этой папке проекта сохранена точная архивная копия финальных источников и экспортов. Это документационные кандидаты, не Minecraft resources.
- Aseprite 1.3.18.6-dev создаёт каждый raster pixel на canvas **512×320**. `author.mjs` описывает вручную заданные кластеры/формы/layout, а `paint.lua` рисует их непосредственно в Aseprite; внешний PNG rasterizer и image generation не использовались.
- Пять слоёв: structural materials; recesses/control bounds; joinery/cloth/states; authored vignettes/native icons; preview-only text. `.aseprite` полностью открывается самостоятельно.
- `*-1x.png` — прямой native PNG export. `*-surface.png` — экспорт без preview text. `*-2x.png` — Aseprite MCP nearest-neighbour render для просмотра; увеличение никогда не становится игровым ресурсом.
- Текст painted из существующих локальных native Minecraft bitmap font providers. Существующие native item sprites повторно используются как preview items; портреты/группы, event moon/forest и миниатюра ворот нарисованы заново в Aseprite. Это style-only иконки, не замена runtime ItemRenderer/PlayerFaceRenderer.
- Для повторного исполнения `author.mjs` нужны исходные локальные font/item inputs, перечисленные в скрипте; они читаются из существующего art input cache, а не модифицируются. Сгенерированные `fonts.json`, `study.json` и read-only input копии сохранены во внешнем study. Редактирование `.aseprite` не требует этого cache.
- Состояния hover/focus/disabled, адаптивное меню и настоящие клики в этой задаче не реализованы. `controls` в study manifest — будущие границы макета, не работающий GUI.
