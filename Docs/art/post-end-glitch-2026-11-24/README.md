# Post-End glitch preview

This folder contains the offline motion preview for the post-End glitch screen. The preview uses the same nine-second duration, purple interference field, cyan and magenta channel separation, and text timing as the Forge renderer. It is a motion and color reference, not captured gameplay.

This is historical development evidence. The 2026-11-26 user-supplied clip replaces this renderer. Its source and frame contract are in `Mods/JEMTwelveEyes/production/secret-ending/README.md`.
