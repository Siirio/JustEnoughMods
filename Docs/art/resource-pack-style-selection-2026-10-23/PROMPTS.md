# Generation prompt set

Generator: built-in OpenAI image generation, explicitly used for the user's requested first round without Gemini.

Shared constraints across all sheets:

- one landscape PNG with exactly nine equal previews in a strict 3x3 grid;
- small corner numbers 1 through 9;
- concept-only Minecraft Java 1.20.1 resource-pack exploration;
- consistent logical pixel scale, hard pixel edges, connected clusters and discrete ramps;
- no blur, smooth 3D/vector residue, watermark or explanatory paragraphs;
- reference images guide hierarchy, cluster discipline, tactile materials and value separation without copying pixels.
