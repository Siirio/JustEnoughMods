# JEM Jalloween v0.1

This folder records the approved Jalloween presentation source and visual review
for the sandbox client generation

## Composition

- `JEM Release v0.3.zip` remains the complete fallback resource owner
- Default-Style Halloween Pack v2.2 overlays its MIT-licensed seasonal assets
- `assets/minecraft/textures/entity/creeper/**` is excluded from the overlay
- The JEM crosshair is authored in `Docs/assets/jalloween/crosshair.aseprite`
- `hysteria-lowest-clouds-disabled.txt` records the exact managed shader sidecar defaults
- The FancyMenu layout uses the supplied illustrated background and approved transparent title
- The installed Halloween GUI and Halloween crosshair packs remain local references because their CurseForge releases are All Rights Reserved

The canonical runtime output is `Client/ManagedPack/resourcepacks/JEM Jalloween v0.1.zip`
and is published only through the native AutoModpack lifecycle
