# Свободная камера

JEMCompat регистрирует переназначаемое действие "Свободная камера" с исходной клавишей F4. Повторное нажатие возвращает прежний вид от лица игрока или от третьего лица. Пока игрок использует предмет, например натягивает лук или трезубец, F4 не включает камеру, чтобы не завершать это действие за игрока. Настройки существующего `options.txt` не переписываются

В режиме камеры мышь поворачивает только временную клиентскую камеру. WASD перемещают её в горизонтальной плоскости, прыжок поднимает, приседание опускает, спринт ускоряет. Игрок остаётся обычной серверной сущностью с прежней физикой, уроном и серверными коррекциями. Клиентские атака, использование и добыча не отправляются от удалённой точки обзора

Перед каждым перемещением JEMCompat проверяет весь путь объёма камеры через настоящие voxel shapes блоков и отступ для ближней плоскости обзора. При отсутствии данных о клиентском чанке движение останавливается у его границы. Камера не запускает загрузку или генерацию новых чанков и не ограничена заданным расстоянием от игрока

Смерть, выход, смена мира, замена игрока и серверный телепорт закрывают режим. Серверный телепорт сохраняет исправленные сервером координаты и взгляд игрока. При обычном выключении возвращаются исходный ракурс и направление взгляда

Реализация использует нативный `Minecraft.cameraEntity`, событие Forge для движения и узкие клиентские mixin для поворота мыши, нативных действий и обработки серверного телепорта. Во время свободной камеры отдельный цикл клавиш боевых навыков Epic Fight 20.14.17 приостановлен, а его обычное управление возвращается сразу после выхода. CameraOverhaul продолжает работать со своими существующими настройками
