# Curated key bindings

The user task8 requests the key map from actual `test jem/options.txt`, restricted to key_ rows. Its2026-10-20 key-only extraction is owned by `Mods/JEMCompat/src/main/resources/assets/jemcompat/input/default_keys.json`. Graphics, names, servers and other personal settings are never imported. Removed Professions entries are omitted. At application, only currently registered KeyMapping names are eligible; absent mods are ignored. Remaining JEI, inventory, tool, spell/vehicle and native controls preserve the observed user's bindings and native conflict contexts.

M opens Xaero world map, V triggers the primary race action, B (Russian И) triggers the utility race action and F6 opens races. Codex resolves the observed competing V/B global actions: backpack Ctrl+B, backpack management Ctrl+V, Tom's terminal Ctrl+G, Cataclysm boots Alt+V, Iron's spellbook Alt+C, Nightfall doppelganger Shift+V, aircraft boost Alt+B. The hidden Deep Dark Regrowth B cheat-sequence binding is unassigned. Modifiers use Forge native KeyModifier, not another input dispatcher. These assignments are implementation choices; they are not a claim that the user already approved their ergonomics.

A clean installation without an options file applies this resource once after actual mappings register. Existing installations change nothing automatically. `/jemkeys preview` lists the exact registered actions that differ and their current→proposed bindings. Its clickable `/jemkeys apply` explicitly applies the preset once. A separate local config/jemcompat-key-preset.applied receipt prevents update-time reapplication. Personal remaps after application stay editable in native Controls. OptionsKeyRetentionMixin continues retaining unknown/removed-mod rows during vanilla serialization. It additionally detects the clean-install boundary, without copying or replacing options.txt.

No profile settings were written during development. Runtime registration, keyboard modifiers and native settings gestures were not exercised by a game launch. Minecraft-day formatting belongs to JEMIdentity's shared MinecraftDays; this input feature does not change game/save/network clocks.
