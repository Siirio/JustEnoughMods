# Curated client preferences

The user task8 requests the key map from actual `test jem/options.txt`, restricted to key_ rows. Its2026-10-20 key-only extraction is owned by `Mods/JEMCompat/src/main/resources/assets/jemcompat/input/default_keys.json`. Graphics, names, servers and other personal settings are never imported. Removed Professions entries are omitted. At application, only currently registered KeyMapping names are eligible; absent mods are ignored. Remaining JEI, inventory, tool, spell/vehicle and native controls preserve the observed user's bindings and native conflict contexts.

M opens Xaero world map, V triggers the primary race action, B (Russian И) triggers the utility race action and F6 opens races. Codex resolves the observed competing V/B global actions: backpack Ctrl+B, backpack management Ctrl+V, Tom's terminal Ctrl+G, Cataclysm boots Alt+V, Iron's spellbook Alt+C, Nightfall doppelganger Shift+V, aircraft boost Alt+B. The hidden Deep Dark Regrowth B cheat-sequence binding is unassigned. Modifiers use Forge native KeyModifier, not another input dispatcher. These assignments are implementation choices; they are not a claim that the user already approved their ergonomics.

A clean installation without an options file applies this resource once after actual mappings register. `/jemkeys preview` lists the exact registered actions that differ and their current→proposed bindings. Its clickable `/jemkeys apply` explicitly applies the key preset once. A separate local `config/jemcompat-key-preset.applied` receipt prevents command-time reapplication. Personal remaps after application stay editable in native Controls. OptionsKeyRetentionMixin continues retaining unknown or removed-mod rows during vanilla serialization. It additionally detects the clean-install boundary, without copying or replacing `options.txt`.

Major Update 4 uses a separate one-time `2026-11-16-major-update-4-v2` receipt. It reissues the curated registered key map because the earlier October receipt already existed before the corrected release. Hotbar 1 through 9 use their normal number keys and the previously unbound FTB Quests action uses Numpad 7. The same migration selects the source-owned order from `default_resource_packs.json`, after filtering out packs that are not available in the current profile. It uses the native `PackRepository` and `Options.updateResourcePacks` path. AutoModpack still does not transmit or own `options.txt`. After the receipt is written, later player key and pack changes are not reapplied by future launches.
