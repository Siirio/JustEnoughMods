## Changes and compatibility

The [1.1.1 notes](https://www.curseforge.com/minecraft/mc-mods/skarrier-mobs/files/9161764) introduce Endorah, Voidrake, Frost, Freeze and void arrows. The selected hotfix addresses Frost's crash. The version jump also includes intervening releases; the exact old/new binary delta is recorded separately rather than assuming the latest short changelog covers the entire upgrade.

Exact binary metadata still requires JavaFML 47+, Minecraft 1.20.1, and declares GeckoLib optional with no minimum version. ManagedPack already contains GeckoLib 4.8.4. No new mandatory library is declared. This is a metadata observation, not proof that every new feature runs correctly.
