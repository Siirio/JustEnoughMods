# Извлечение чар на точиле

Обычный ПКМ открывает нативное точило. Если игрок держит зачарованную вещь в основной руке и нажимает Shift + ПКМ, сервер снимает первое зачарование в порядке списка предмета и выбрасывает у точила одну зачарованную книгу с тем же уровнем. Проклятия обрабатываются тем же способом. Зачарованная книга в руке не обрабатывается

Возврат опыта составляет `floor(фактически потраченные XP × 70 / 100)` для снятого зачарования. Это очки опыта, а не уровни. Если одна операция нанесла несколько чар, её реальная стоимость делится поровну между ними, а неделимый остаток по одному очку получают первые чары в сохранённом порядке. При объединении вещей подтверждённая история затрат переносится вместе с соответствующими чарами. Сервер отмечает возвращённые платежи, чтобы копия ItemStack не вернула те же XP второй раз

Стоимость записывается только после успешной серверной операции наложения чар в нативном столе зачарования или наковальне, включая установленный EasyAnvils, который вызывает нативный `AnvilMenu.onTake`. Для вещи без записанной истории действует отдельное решение пользователя: при первом извлечении она получает фиксированное количество очков XP, эквивалентное трём уровням от нуля. Следующие извлечения из этой же вещи не получают повторную фиксированную выплату. Новые чары с записанной реальной стоимостью по-прежнему возвращают только 70% от неё. Зачарования из добычи, торговли и команд не получают придуманную стоимость

Запись истории, одно снятие и выброс книги не меняют обычный экран точила, остальные чары, имя, прочность, атрибуты или сторонний NBT. Возврат XP обходит общий множитель наград WorldBossTiers, потому что возвращается уже оплаченная сумма, а не новая награда

Решения пользователя от 2026-10-26 и 2026-10-27: считать 70% от фактически потраченных XP, делить общую стоимость поровну, снимать проклятия с вещей, не применять Shift + ПКМ к зачарованной книге и после отдельного решения выдавать для старой вещи одну фиксированную компенсацию в три уровня. Технический выбор Codex: хранить доли оплаченных операций в NBT вещи и одноразовые идентификаторы возврата в серверных SavedData

Статус: `in testing` до пользовательской приёмки. Игровой запуск и автоматические тесты этим описанием не разрешаются и не подтверждаются
