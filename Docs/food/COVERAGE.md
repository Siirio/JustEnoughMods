## Native bite admission

JEMFood wraps the actual logical-server BlockState.use call. A scoped receipt requires the same player's native FoodData.eat or positive native food-level insertion, a consuming return and an actual portion/state transition. Failed use, menu opening, knife slicing, prediction, creative and spectator calls do not award food bonuses. The seam needs no optional classes. The 22 declared block-bite IDs remain data entries, not a claim that every block supports direct eating. Native Cookery portions use the same receipt when their exact block ID is assigned. Runtime bite acceptance remains unverified without a player run.
