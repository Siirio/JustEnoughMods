# JEM Races

JEM Races — dedicated-server-authoritative система из пяти рас. Раса и её мастерство принадлежат подтверждённому `JEM Identity` account ID, а не отображаемому нику. Любая раса совместима с любой профессией.

## Как открыть и управлять

- Первый подтверждённый вход без выбранной расы автоматически открывает выбор.
- После выбора: `/smp` → `Расы`. Прямые `/jem role` и `/jemrole` удалены.
- `V` применяет сигнатурное умение; `B` выполняет контекстную способность. Для Странника Пустоты удержание `B` заряжает снаряд, а `Shift+B` включает Отрицание гравитации. У Рождённого в цветении `B` переключает Живую тропу.
- Обе игровые клавиши переназначаются в стандартных настройках Minecraft.
- Экран всегда показывает ровно три равные карточки; две остальные доступны стрелками или колесом. Карточка содержит лор, пять усилений, два недостатка и три ступени сигнатурного умения.

## Расы

| Раса | Пять усилений | Два недостатка | Сигнатура и дерево |
|---|---|---|---|
| Предки | Страж предков; мирные животные не убегают; скидка 20%; +30% среднего выхода бартера; Хор жизни | Нарушенная клятва; приоритет для разбойников | Хор жизни: лечение → увеличенная область и снятие отрицательных эффектов → поглощение при избыточном лечении |
| Странники Пустоты | безопасное возвращение из Пустоты; родство с существами Энда; заряжаемый снаряд; Засада разлома; Отрицание гравитации | Водный разлом; −3 сердца | Засада разлома: удар → дальность и временная приманка → дезориентация обычных врагов |
| Рождённые в цветении | Власть зелени; Живая тропа; лесные враги игнорируют; фотосинтез; Второе цветение | двойной огненный урон; −4 сердца вне зелёной среды | Власть зелени: корни → распространение между целями → временная живая роща |
| Заражённые скалком | Эхо-зрение; Скалковые жилы; Поглощение эха; подземное усиление; +15% XP | −4 сердца на прямом солнце; перегрузка от взрывов | Скалковые жилы: связный путь 32 → 48 блоков → выбор взглядом среди выходов до 64 блоков |
| Сердца Незера | плавание и дыхание в лаве; иммунитет к обычному огню; питьё лавы; Адское извержение; дружелюбие пиглинов | нарастающая водная скованность; −4 сердца на морозе | Адское извержение: разлом → цепь разломов → временная вулканическая зона |

Успешные применения сигнатуры повышают отдельное расовое мастерство: уровень 2 открывается после 10, уровень 3 — после 30 применений. Прогресс, cooldown, резонанс и переключатель Живой тропы сохраняются в `jem_roles` SavedData. Смена расы сбрасывает только расовую ветку; профессии не затрагиваются.

Старые записи мигрируют детерминированно: `HUMAN` → Предки, `DWARF` → Заражённые скалком, `ELF` → Рождённые в цветении. Существующие active ticks и право первой бесплатной смены сохраняются.

## Профессии и дерево навыков

`/smp` → `Профессии` выполняет server-validated открытие нативного Pufferfish's Skills. Команды `/jem professions` и `/jemprof` удалены. Канонический datapack `Client/ManagedPack/config/paxi/datapacks/jem-profession-skills` должен одновременно присутствовать в `Server/config/paxi/datapacks`; без серверной копии Pufferfish загружает ноль категорий и показывает пустое окно.

JEM не рисует копию профессий и не хранит вторую модель узлов: категории, XP, уровни, очки и разблокировки принадлежат Pufferfish's Skills, а JEMProfessions только принимает подтверждённые сигналы прогресса и применяет эффекты реально открытых узлов.

## Интеграции и границы

| Система | Проверено или переиспользовано | Реализация JEM | Ограничение |
|---|---|---|---|
| JEM Identity | `IdentityPolicy` и подтверждённый account ID | выбор, прогресс и действия разрешаются через account ID | Offline-mode Minecraft UUID/ник не является владельцем прогресса |
| Iron's Spells 3.15.6 | фактический JAR и API регистрации заклинаний просмотрены | innate сигнатуры используют отдельный server-validated racial cast без предмета | Native wheel Iron's требует физический spell container; сигнатуры не вставляются в него и не становятся scroll/loot |
| JEM Economy | `CoinTradePriceEvent` и `CoinTradeContext` | ровно одна скидка 20% в authoritative quote | Неизвестная сторонняя экономика требует явного adapter вместо определения по имени |
| Vanilla merchants | `TradeWithVillagerEvent`, native offers и slots | возврат разницы до фактической цены 80% только для покупок за изумруды | Не меняет продажу игроком предметов торговцу |
| Piglin barter | global loot modifier для `gameplay/piglin_bartering` | независимое 30% дублирование уже выпавшего stack сохраняет распределение | Сторонняя система, не использующая этот loot table, требует отдельного modifier/adapter |
| Animals and mounts | `Animal` и native `AvoidEntityGoal` | узкий Mixin отключает страх перед Предком | Нестандартное мирное существо вне `Animal` требует явного compatibility hook |
| End kin and bosses | точные entity IDs из server config | дружелюбие только для allowlist; boss denylist имеет приоритет | Неизвестные modded IDs администратор добавляет в `jem-races-server.toml` после проверки |
| Biomes | vanilla biome tags, Lush Caves и climate settings | единая классификация зелёной среды | Экзотический биом с нетипичным климатом требует tag/config расширения |
| Boss/event boundaries | существующие `ServerPlayerTeleportMixin` и `BossTeleportSafety` | все same-dimension racial teleports проходят общий серверный gate | Отдельной копии boundary policy в JEM Races нет |
| Temporary path | server SavedData с dimension, block position и expiry | блоки живут ровно 800 ticks и удаляются после повторной загрузки chunk | Активный путь использует oak leaves как существующий семантический block, без нового registry object |
| Profession UI | Pufferfish's Skills API и Paxi | SMP packet открывает native screen; сервер получает тот же datapack | Игровая приёмка после публикации остаётся ручной по правилам проекта |

## Серверная конфигурация

`jem-races-server.toml` владеет cooldown и длительностями Стража, Хора жизни, Засады, снаряда, Отрицания гравитации, Второго цветения, питья лавы и лавового дыхания. Там же находятся точные списки существ Энда и исключённых боссов; расширения требуют реального registry ID.

## Авторитет и производительность

Client только показывает экран, HUD и отправляет ограниченные действия. Server проверяет identity, выбранную расу, nonce, cooldown, цель и безопасное место. Атрибуты используют стабильные UUID. Поиск сухого места сначала использует последнюю подтверждённую платформу, затем ограниченные радиальные пробы; связный скалк ограничен 2048 позициями. Временные сущности и зоны имеют серверный expiry, а Живая тропа переживает выгрузку чанка и перезапуск.
