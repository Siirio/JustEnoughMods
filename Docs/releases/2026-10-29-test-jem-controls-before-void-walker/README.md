# test jem controls before Void Walker toggle

Captured from the active `test jem` profile before registering the requested Void Walker on/off key.

The snapshot preserves all 259 saved `options.txt` key rows in their original order and the two auxiliary keybinding files used by Fzzy Config and Punchy. The profile had no saved action on F7 or F12. F7 was selected as the new Void Walker toggle because it is the first free function key that does not overlap Minecraft's hardcoded F1/F3 controls or the saved F2, F4, F5, F6, F8, F9, F10 and F11 actions.

This is a controls-only development snapshot. It does not replace the immutable 2026-10-26 original-profile snapshot and contains no account, world, waypoint or unrelated gameplay data.
